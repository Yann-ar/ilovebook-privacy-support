# ilovebook 隐私政策

生效日期：2026年10月4日

藏书资料主要保存在你的设备上。这里说明在线查书、封面补全，以及你对数据的选择。

## 一览

- **本机保存**：藏书、书架布局和阅读计时保存在设备上。
- **不做广告追踪**：没有广告或第三方行为分析 SDK。
- **联网有说明**：搜索和自动封面补全会访问第三方书目服务。

## 01 适用范围与联系方式

本政策适用于 Yann 提供的 ilovebook iOS 应用及其公开法律说明网站。开发者／运营者为 Yann，联系邮箱为 yesiyang@outlook.com。

ilovebook 用于整理个人藏书、布置书架和阅读计时。当前版本不要求注册账号，也没有由开发者运营的藏书云端数据库。本政策说明开发者、设备系统与第三方书目服务各自处理的数据。


## 02 设备上保存什么

为提供应用功能，ilovebook 在设备上保存你输入、选取或编辑的资料，以及从书目服务取得并保存的资料。开发者不会自动接收这些完整记录。

- 书籍资料：书名、作者、ISBN、页数、出版社、出版年份、封面、书脊颜色与文字样式、加入时间及所属分类。
- 整理与显示资料：分类名称和顺序、书架布局、书本与摆件位置、摆件选择、信息板文案及界面偏好。
- 阅读资料：当前选择的书籍、计时开始时间和累计阅读时长。

## 03 哪些操作会产生网络请求

书库搜索同时提供在线查书。在搜索框输入至少两个字符或有效 ISBN 后，应用会自动向书目服务发送当前查询文字；这可能包含书名、作者或你输入的其他内容，无需再点击联网按钮。编辑书籍时点击“按 ISBN 查找”，会发送所填 ISBN。

启动应用后，对缺少封面或需要纠正封面的藏书，应用可能自动以已有书名查询书目，并按查询结果访问书目详情页和封面地址；下载封面时也可能发送对应 ISBN 或封面标识。补全结果可能更新本机的封面、书脊颜色、ISBN、页数、出版社或出版年份。

当前实际使用的服务包括豆瓣读书（book.douban.com）、Goodreads（goodreads.com）、Open Library 封面服务（covers.openlibrary.org），以及书目结果提供的图片资源地址。请求直接从设备发出，不经过开发者自建服务器。应用不会为这些请求上传整份书库、分类名称、书架布局或阅读计时。

第三方会接收到请求所需的查询内容或资源标识，以及连接产生的 IP 地址、请求时间和网络请求头等信息。系统网络组件可能保留缓存或网站 Cookie。第三方的记录、保留期限和处理方式适用其自身政策，开发者无法替这些服务承诺删除或保密。


## 04 广告、分析与系统权限

当前应用没有广告、第三方行为分析 SDK 或开发者自建的使用统计、崩溃上报服务；不主动读取广告标识符，也不为跨应用广告追踪建立用户画像。

当前版本不请求相机、麦克风、相册、通讯录、定位或健康数据权限。应用可能通过 Apple 系统日志记录运行错误；用户或系统选择向 Apple 分享诊断信息时，适用 Apple 的相关设置和政策。


## 05 第三方网站、地区与邮件支持

公开隐私政策和使用条款网站由 GitHub Pages 托管。网站没有我们添加的广告、统计脚本或 Cookie；GitHub 为提供托管和安全服务，可能处理 IP 地址与访问日志，适用 GitHub 的隐私声明。打开网页或外部链接后，相关服务的数据处理不由 ilovebook 控制。

书目、图片、网页与邮件服务可能由位于不同国家或地区的服务器提供；请求数据可能在你所在地区之外处理。我们不将本机完整书库发送给这些服务。

你主动发送支持邮件时，我们会收到邮件地址、正文及你选择提供的附件，仅用于处理咨询、排查问题、响应数据请求和必要的后续沟通。请不要发送密码、付款信息或无关的私人资料。咨询结束后，我们会在不再需要且没有法定保留义务时删除相关邮件。


## 06 保存期限、备份与删除

藏书和相关设置通常保留在设备上，直到你修改、删除相关内容或在 iOS 中选择“删除 App”。删除书架会移除该书架的摆放，书籍仍保留在书库；删除分类时，应用会按操作提示保留或转移书籍。要移除某本藏书，请使用该书的删除操作。

删除一本书不会自动清除所有历史计时、偏好或布局标识；移除封面后，应用也可能在后续启动时重新补全。需要清除应用在本机保存的全部资料时，请选择“删除 App”，而不是保留文稿数据的“卸载 App”。

当前应用没有自己的跨设备同步或云端恢复功能。如果你启用了 iCloud 设备备份或电脑备份，系统可能把应用数据纳入备份。系统备份、诊断日志及第三方网络记录可能按各自规则保留；删除本机数据不会同步删除这些副本，请通过相关服务管理。

开发者不能远程读取、恢复或删除你设备中的藏书。删除和设备故障可能造成数据丢失，请自行妥善保管重要资料。


## 07 你的选择与数据请求

你可以在应用内查看、修改和删除藏书、分类及书架内容；无需提供姓名、电话或邮件地址即可使用整理和阅读计时功能。

当前没有独立的联网查询或自动封面补全开关。若希望避免书目查询和图片请求，可以在断网环境使用已保存的资料，并避免打开外部网页或发送邮件；在线查询与补全将无法完成。请不要在查询框输入与查书无关的敏感资料。

如果你希望了解、取得、更正或删除你曾通过支持邮件提供给我们的个人信息，或对处理方式提出异议，请联系 yesiyang@outlook.com。我们会按适用法律核实并响应，不会要求你提交整份书库。你依法享有的其他权利不因本政策而受到限制。


## 08 未成年人、保护措施与更新

ilovebook 是通用的个人藏书工具，不专门面向儿童，也不要求提供年龄或儿童身份信息。未成年人应在监护人指导下使用在线查询和邮件支持，避免提交私人资料；如你认为我们收到不应处理的未成年人信息，请联系我们。

应用使用 iOS 提供的设备隔离与存储机制，并通过 HTTPS 访问当前配置的书目服务。请保护设备、解锁凭证及备份；任何系统和网络都无法保证绝对安全。

功能或数据处理方式发生变化时，我们会更新本政策及生效日期。涉及依法需要另行告知或同意的变化，会按适用要求处理。应用内可离线阅读随当前版本提供的政策，网站公布最新版本。
